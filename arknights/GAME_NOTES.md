# 明日方舟游戏知识（托管时学到、容易记错的事实）

> 只记**通用的游戏和工具事实**，不记账号数据。每条注明来源：用户、游戏数据（ArknightsGameData）、实测、MAA 源码。发现新的就加进来；之前写错的就直接改正，并注明哪天改的。

## 战斗与理智
- **放弃行动会退还全部理智**，普通和突袭都一样（用户；2026-11-16 实测：放弃前 75，放弃后 75，结算显示“理智返还 15”）。
- **二星通关不退理智**，也拿不到三星首通奖励（用户）。所以作业一漏怪，就该放弃重打，不要打完。
- 普通关卡的放弃流程（实测）：左上角齿轮 → 确认框“放弃行动将会恢复N理智（全部返还）/ 是否放弃行动？”→ 点右下的“放弃行动” → “任务失败 / 点击画面以继续” → 结算“理智返还 N”。集成战略（肉鸽）的确认框位置不同。
- 战斗顶栏：左边是敌人计数 `已击杀/总数`，右边是塔形图标加生命值。EX 关一般 3 点生命。

## 支线活动（SideStory）
- **活动任务的奖励要手动领取**（用户纠正，2026-11-16）：在活动页的任务入口（「时间啊，向前！」是“晨曦所见证的”）里领，页面有“一键领取”按钮（自动化时 OCR 找这几个字点一下即可）。领过的显示 COMPLETED。MAA 的“领取奖励”只领日常和周常，不领活动任务。代币估算要把任务奖励算上，并记得在商店关闭前领：例如「时间啊，向前！」通关 TL-1~10 共 750，EX-1~8 共 480，S-1~4 三星共 280，通关活动关 15/45/85 次共 300（游戏数据 activity_table 的 missionData）。
- EX、S 关普通模式首通掉源石和少量代币（EX-1 是 1 源石加 40 代币）；突袭首通只给源石，不给代币（stage_table 的 displayRewards）。
- 关卡关闭（endTime）后商店还会开一周（rewardEndTime）。
- 活动关页面的突袭开关（2026-11-17 实测）：底部“演习”左边，普通模式下写“突袭模式”、开始按钮“开始行动”；点一下变成突袭模式，开关写“普通难度”、按钮“开始突袭”，右侧面板变红并列出附加条件。突袭三星的奖励显示在“报酬”里（“三星获得”）。
- 「时间啊，向前！」的 TL-7、TL-8、TL-9 每次 21 理智、掉 21 代币（MAA 日报）。

## 剿灭
- 每周上限 1800 合成玉，周一 4:00 重置。
- **单次最多给的合成玉**取决于关卡（campaign_table 的 gainLadders，400 击杀）：当期轮换剿灭 370；常驻的切尔诺伯格 260、龙门外环 330、龙门市区 350。所以每周要打 **5 次**。
- **常态事务代理卡**：打满过 400 击杀的剿灭可以直接代理，每次消耗 1 张。卡来自日常任务奖励，**会过期**（物品说明；用户）。
- 剿灭本身每次 25 理智。

## 保全派驻
- 森空岛数据里的 `tower` 就是保全派驻；`tower.reward` 是本期奖励进度，`termTs` 是本期结束时间。
- **每期奖励上限**：数据增补条（`mod_update_token_1`）60 个、数据增补仪（`mod_update_token_2`）24 个（climb_tower_table 的 detailConst）。
- 记录满层的关可以扫荡，每次消耗 2 张代理卡（sweepCostCount）。
- 扫荡的界面（2026-11-20 实测）：终端页右上 TO-DO 卡片（显示本期奖励进度）进塔列表，点塔的卡片图进详情；“全权委托”勾上时开始按钮下方显示“-2”。确认框写“确认使用2张常态事务代理卡 执行一次保全派驻全权委托代理指挥？”，下面按过期时间分组列出持有的卡（如“2天 2”“9天 5”），先用最早过期的。一次扫荡给数据增补条 20、增补仪 10（本期上限 60、24）。
- 从塔列表按返回键，会先到“常态事务”页（剿灭本周合成玉进度），再回主界面。
- 真打保全时要先排好上场队列，PRTS 上有攻略（用户）；maa-cli 用 `ssscopilot` 执行。

## 基建
- **游戏内的“预设队列”**：每个房间最多存 3 组，只有手动点 ⇄ 或“进驻总览”右下的“队列轮换”才会切换（实测，没找到定时设置）。MAA 换班直接把人放进房间，不读这些预设。
- 心情上限 24。工作时每小时约掉 1 点，技能会加减（如 −0.25、+0.25）。
- 森空岛的设施编号对应位置（building_data 的 layouts）：B1 层 slot_24/25/26，B2 层 slot_14/15/16，B3 层 slot_5/6/7，各自从左到右是 01–03。
- **双芯片在制造站合成**：芯片组 ×2 加芯片助剂 ×1，**每个只要 1 秒**（building_data 的 manufactFormulas，costPoint = 1；赤金是 4320 秒，经验记录是 10800 秒）。临时切过去做完马上切回即可（用户确认，2026-11-16）。加工站能把同组的另一职业芯片组 3 换 1（有损耗）。

## 商店与货币
- **芯片助剂**：采购凭证区（红票）每个 90 采购凭证，不限量（2026-11-16 实测）。
- 凭证交易所的资质凭证区（绿票）分三层，第三层要累计消费才解锁；库存每月 1 日刷新。
- 活动商店里不限量的那几种 T3（如轻锰矿 30、扭转醇 25、研磨石 35 代币）比刷主线关划算：主线最优关卡每个约要 38、34、45 理智（企鹅物流）。

## 关卡开放日（MAA StageManager）
- 龙门币本 CE-6：周二、四、六、日；经验本 LS-6：每天；红票本 AP-5：周一、四、六、日；技巧概要 CA-5：周二、三、五、日；碳本 SK-5：周一、三、五、六。
- 芯片本：PR-A（医疗、重装）周一、四、五、日；PR-B（术师、狙击）周一、二、五、六；PR-C（先锋、辅助）周三、四、六、日；**PR-D（近卫、特种）周二、三、六、日**。
- PR-x-1 掉芯片，18 理智；PR-x-2 掉芯片组，36 理智，两个职业大约各一半（企鹅物流：PR-D-2 特种芯片组每次 0.5 个）。

## MAA / maa-cli
- 一次给多个作业（多作业模式）时，要从**关卡所在的地图界面**开始，列表里的关卡要在同一区域（左右滑动就能找到），每项可以单独标普通或突袭（MAA 文档 manual/introduction/copilot.md、protocol/integration.md 的 `copilot_list`）。2026-11-15 从主界面开始，结果它在主界面一直滑动，当时误记为“只认主线关卡”（2026-11-17 改正）。单个作业要从有“开始行动”按钮的关卡页开始，按页面当前的模式打。
- MAA 和 maa-cli 的官方文档副本在 `ops/maa/upstream/`，用某个参数或功能前先查。
- **`maa copilot --raid` 对单个作业不起作用**（2026-11-17 查明）：它只用于 maa-cli 自己的主线导航，MaaCore 收到的参数里没有突袭，按页面当前显示的开始按钮开打。活动关的突袭要先在关卡页自己切到突袭模式。
- 自定义基建排班里，同类房间按 MAA 识别到的顺序对应：B1 → B2 → B3，同层从左到右。
- maa-cli 不处理排班文件里的 `period`，要用任务的 `variants`（`condition = { type = "Time", ... }`）选 `plan_index`。
- 领取奖励的选项：`award` 是日常和周常任务；`mail` 邮件；`recruit` 每日免费单抽；`orundum` 幸运墙合成玉；`mining` 限时开采许可；`specialaccess` 特别访问月卡；`signinevent` 活动签到。
- 电脑可用内存不够时，MaaCore 截图拿到空图，报 `image is empty / Unhandled out of memory` 并中断任务，战斗会停在暂停画面（2026-11-16 实测）。
- MAA 的任务资源（`resource/tasks/`）可以直接借用：例如 `BattleHpFlag` 读生命值，集成战略界园的放弃战斗流程是 `LeaveOperation → GiveUpOperation → ConfirmToGiveUp`。坐标按 1280×720，本机 1600×900 要乘 1.25。

## 被挤下线（2026-11-21 实测，用户配合）
- 一个账号只能在一处登录。另一处登录后，这边不会马上有反应，**只有发生联网请求时才弹窗**：任务页、邮件列表、好友页这类本地能显示的界面不会触发；在公开招募点「聘用候选人」立刻弹出。
- 弹窗文字「登录认证已失效，请重新登录」，下方一个对勾按钮；重新登录不用输账号密码，点登录即可。
- MAA（v6.22）把它识别为 `OfflineConfirm`：普通任务在这里停下，但 `.out` 汇总仍写 Completed，只有 `state\debug\asst.log` 里 `SubTaskStart` 的 `"task":"OfflineConfirm"` 能看出来；「开始唤醒」会点对勾重新登录（`OfflineConfirmImpl`），把另一处挤下线。
