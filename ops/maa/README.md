# 明日方舟托管流程（maa-cli，blender 账号）

> 本文描述**现在实际在跑的**流程。每次改动流程（脚本、任务配置、排班、队列、计划任务）都要同步改这里，并在文末“变更记录”加一行。
> PC 运维的通用内容（MCP 管线、exec、清理）见 `ops/README.md`；这里只写游戏托管。游戏机制和工具的已知事实见 `arknights/GAME_NOTES.md`。最后更新：2026-11-17。

## 1. 一句话概览

Windows 计划任务每天 0:00、8:00、12:00 各启动一次 `run.ps1 -Task daily`，依次完成：
1. 打开模拟器；
2. 打活动 EX/S 首通；
3. MAA 日常（基建两班排班、剿灭、刷活动关、公招、信用、领奖、识别）；
4. 导出数据并同步森空岛；
5. 关模拟器。

每次结果记一行在 `D:\Projects\maa-cli\logs\runs.log`。

```
计划任务 (0:00 / 8:00 / 12:00)
  └─ run.ps1 -Task daily
       ├─ 加锁、检查（没开界面版 MAA、模拟器不在别的会话）
       ├─ 启动雷电模拟器 0 号，等安卓开机
       ├─ annihilation_gate.py   本周剿灭满了就注释掉剿灭任务
       ├─ maa run wake           打开游戏到主界面
       ├─ ev_run.py              活动 EX/S 首通（OCR 导航 + prts.plus 作业 + 漏怪即退）
       ├─ ocr.py --stop          关掉 OCR 服务，释放内存
       ├─ maa run daily          日常队列（见第 3 节）
       ├─ 关模拟器
       ├─ export_data.py         从 MaaCore 日志导出仓库、干员
       ├─ node sync.mjs          森空岛同步（练度、基建、库存）
       └─ after_rebuild.py       改建完成后自动改回无人机（已完成，现在不做事）
```

## 4. 自动判断的规则

- **剿灭开关**（`annihilation_gate.py`，每次日常前运行）：
  - 读最近一次森空岛导出：本周合成玉已满 1800，就注释掉剿灭任务，否则恢复。
  - 每周一 4:00 重置；重置前的导出按“未满”处理。
  - 当期剿灭单次最多 370，所以每周会打 5 次。
- **活动首通**（`ev_run.py`）：
  - **队列**：写在脚本的 `QUEUE` 里，依次是普通 EX-2→8、S-1→3，再打全部突袭。完成记录在 `state\ev_done.json`，失败次数在 `state\ev_fail.json`。
  - **导航**：每一步先 OCR 确认画面，只点认出来的文字：主界面横幅“时间啊”→ 区域 → `TL-EX-n`。认不出就报错、回主界面，不盲点。
  - **理智**：在关卡页读当前理智和消耗，不够就停下，留给下一次日常。
  - **内存**：剩余可分配内存不足 6 GB 也停下。内存不足会让 MAA 截图失败、中途退出。
  - **突袭**：活动关页面底部“演习”左边是模式开关，普通模式下写“突袭模式”、开始按钮是“开始行动”；突袭模式下写“普通难度”、按钮是“开始突袭”。`set_mode` 按队列要求点开关，再从按钮文字确认，确认不了就不打。maa-cli 的 `--raid` 对单个作业无效（只用于它自己的主线导航），MaaCore 按页面当前的按钮开打。
  - **漏怪即退**：每 3 秒读一次顶栏的敌人计数和生命值，连续两次低于开局，就结束 MAA 并放弃这局（放弃全额退理智；二星通关不退，也拿不到首通奖励）。
  - **放弃流程**：齿轮 → “是否放弃行动”框里点靠下的“放弃行动” → “任务失败”点一下 → “理智返还”点一下。
  - **重打与跳过**：失败后当场重打一次；两次日常都失败才跳过这一项，等人换作业。
  - **OCR 服务**：用 CPU，运行结束时一定关掉。
- **无人机**（`after_rebuild.py`）：3 个贸易站都到 3 级后改回 `Money`。2026-11-16 已完成，之后不再做事。

## 8. 出问题时

| 现象 | 看哪里 / 怎么办 |
|---|---|
| 某次日常特别久 | `runs.log` 最后几行；`asst.log` 末尾看 MAA 在做什么。曾因内存不足停在暂停的战斗里 3 小时，现已加内存检查和放弃流程 |
| `[ev] ... FAILED` | `logs\<时间>-ev.log`，以及 `asst.log` 里的 `ERR`。`image is empty / out of memory` 是内存不足 |
| 模拟器离线（`adb devices` 显示 offline） | `ldconsole quit --index 0`，下一次日常会重新开 |
| exec 或 Blender 连不上 | 用户可能在重启服务，等一会儿，不要反复连 |
| 森空岛同步退出码 3 | 登录失效，需要用户扫码（`node login.mjs`，二维码只在电脑上打开） |

手动命令（经 exec 用 `Start-Process` 让它在后台跑，再轮询 `runs.log`）：

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File D:\Projects\maa-cli\run.ps1 -Task daily
```

`-Task` 可换成 `wake`、`infrast`、`inventory`、`chips`；加 `-KeepEmulator` 跑完不关模拟器。只跑活动首通：`ev_run.ps1`（`-Dry` 只导航、读理智，不打）。
