## 场景结构

- 集合按图上编号：`A1` `A2` `A3` `A3-1` `A4` `A5` `B1` `B2` `B3` `廊道` `地面`，每座再分 `木构 / 墙体门窗 / 屋面 / 匾联`，B1、B3 下分亭、院门、陈设、铺地。
- 坐标：X 向东、Y 向北，原点在 B1 中轴与 A1/A2 南山墙线交点；Z=0 为堂、廊台明面，庭院面 −0.60 m。
- 瓦（约 5.8 万片）、椽、斗栱、柱、柱础、栏杆、竹叶、树叶都是几何节点实例（`XY_Instancer`）。视口里瓦和叶子自动换成低面数代理，渲染时用完整几何（节点里的 Is Viewport 开关）。全场渲染约 990 万三角面，视口约 250 万（四分之一）。
- 地面铺装每块石板都是独立的带倒角几何，块间留缝，每块有自己的色差；台明阶条石、台帮、垂带踏跺、池壁压顶都是实体。

## 尺寸来源

- 平面：柱位从平面图红点自动识别后取整（如 A1/A2 七开间 3.30 m、通面阔 23.10 m，进深约 12.05 m，前廊 2.05 m）；各座位置、院落、廊道、台阶、水池轮廓按平面。
- 高度：两张剖面。台明 +0.60 m，檐口瓦面约 4.9 m，屋面交点约 9.1 m，正脊顶约 10.2 m；堂的屋面曲线直接取 3-3 剖面 A5 的实测折线。
- 航拍机位用 9 个已知点反算（误差约 4 px），用来核对各座位置、高度和 B1 院树池位置。

## 推断的部分

1. 各堂背立面与室内：资料只给出局部，背面按前檐同一套开间做法布置窗；室内不建，只做前廊平棊天花。
2. 斗栱构成：按照片做成双杪（两跳华栱 + 令栱 + 耍头），廊、亭用简化的一斗三升；具体栱长、斗高是按比例估的。
3. 院门门屋两侧小房间、两厢内部，A3-1 的门窗分格：只在航拍和立面上看到外轮廓。
4. 廊道与堂、亭交接处的屋面搭接、B3 北廊背墙、B2 北侧院墙的高度。
5. B2 竹林的种植范围和甬道走向（按航拍与一张照片）；B1 四棵紫叶树的形态是程序生成的。
6. 许愿池深度、池底卵石；碑的北面黑底红字“許願池”、南面白石面，按两张照片分别看到的两面。
7. 材质颜色：照片经过调色，按自然日光下的灰瓦、铁红油饰、白灰墙、青砖、花岗岩重新取色。

## 仍与资料有差异的地方

1. **B1 院树池位置**：按航拍定位。A2 那张照片在排版时被裁切并纵向拉伸约 1.47 倍，无法唯一反算机位，它暗示的西北角树位与航拍不一致，这一点没有解决；A2 对照图为看清立面隐藏了树木。
2. **楹联文字留空**：照片里只能认出零星几个字，按要求没有补字。B3 北亭匾额同样留空。已做出的匾额：A1“鳴鳳學堂”、A2“芙蓉學堂”、A5“太華春光”、B1 亭“春色滿園”、B3 南亭“步蟾”。
3. **B1 亭碑**：照片上是金色人物浮雕，这里只做了金色浮雕板的位置和形制，没有雕人物。
4. 山面窗带、门窗棂格比实物简化；瓦面没有做局部破损、补瓦和青苔。
5. 除航拍外，其余对照机位是按照片手工对位的，透视接近但不是严格反算；B3 南向照片也有排版拉伸。
6. 院外环境按要求未做，场地外是素土地面。
