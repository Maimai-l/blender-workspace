| 内容 | 位置 |
| --- | --- |
| Blender 文件 | `xingyuan.blend`（Blender 5.2.3，Cycles 显卡渲染，约 36 MB） |
| 对照机位渲染（9 张） | `交付\对照渲染\`，文件里对应相机 `CAM_对照_*` |
| 与参考照片的并排对比 | `交付\并排对比\`（`并排对比_总览.jpg` 是 9 组合在一起） |
| 效果图（11 张，1920×1080） | `交付\效果图\`，对应相机 `CAM_效果_*`；其中 garden / lotus / pond / plaza / site 是院外环境 |
| 生成脚本 | 本仓库 `xingyuan/scripts/`（建筑 `build_all.py`，院外环境 `build_env.py`） |

仓库 `xingyuan/deliverables/` 里有并排对比图和效果图的 JPG 副本。

重建方法：
1. 把 `xingyuan/scripts/lib/` 复制到 `C:\Users\blender\Documents\xingyuan\lib\`。
2. 在 Blender 里运行 `scripts/build_all.py`，再运行 `scripts/build_env.py`，最后运行 `scripts/organize.py`。
3. 对照图和效果图用 `scripts/render_views.py`（机位在 `lib/views.py`、`lib/heroes.py`）。
4. `scripts/check_*.py` 是穿插、法线和共面重叠检查。

院外环境的形状和种植点位由 `xingyuan/env/make_env.py` 在本地生成（`lib/xy_env_data.py`、`lib/xy_env_grid.py`），改了点位要先重跑它。

## 场景结构

- 集合按图上编号：`A1` `A2` `A3` `A3-1` `A4` `A5` `B1` `B2` `B3` `廊道` `地面` `环境`。每座建筑再分 `木构 / 墙体门窗 / 屋面 / 匾联`，B1、B3 下分亭、院门、陈设、铺地。`环境` 下分地形水体、铺地、构筑物、乔木、灌木、水生与地被、草坪。
- 坐标：X 向东、Y 向北，原点在 B1 中轴与 A1/A2 南山墙线交点；Z=0 为堂、廊台明面，庭院和院外铺地面 −0.60 m，池塘水面 −1.45 m。
- 以下都是几何节点实例（`XY_Instancer` / `XY_Foliage`）：
  - 瓦（约 5.8 万片）、椽、斗栱、柱、柱础、栏杆、竹叶；
  - 院外的树叶、柳条、荷叶、草、置石。
- 院外种植的数量：
  - 近处乔木 263 棵，远景树 891 棵；
  - 灌木、绿篱和林下灌木约 2,830 丛；
  - 荷叶 1,595 丛，岸边植物约 720 丛，置石 156 块，草约 47 万丛。
- 视口里，叶子换成少量低面数代理，细枝不显示；渲染时用完整几何（节点里的 Is Viewport 开关）。全场视口约 790 万三角面（其中建筑约 250 万）。在 RTX 5070 Ti 上，1080p、192 采样的效果图每张约 12 秒。
- 地面铺装每块石板都是独立的带倒角几何，块间留缝，每块有自己的色差；台明阶条石、台帮、垂带踏跺、池壁压顶、院外路缘石都是实体。

## 推断的部分

建筑：
1. 各堂背立面与室内：资料只给出局部。背面按前檐同一套开间做法布置窗；室内不建，只做前廊平棊天花。
2. 斗栱构成：按照片做成双杪（两跳华栱 + 令栱 + 耍头）；廊、亭用简化的一斗三升。具体栱长、斗高按比例估的。
3. 院门门屋两侧小房间、两厢内部、A3-1 的门窗分格：只在航拍和立面上看到外轮廓。
4. 廊道与堂、亭交接处的屋面搭接；B3 北廊背墙；B2 北侧院墙的高度。
5. B2 竹林的种植范围和甬道走向，按航拍与一张照片；B1 四棵紫叶树的形态是程序生成的。
6. 许愿池深度、池底卵石；碑北面黑底红字“許願池”、南面白石面，按两张照片分别看到的两面。
7. 材质颜色：照片经过调色，按自然日光下的灰瓦、铁红油饰、白灰墙、青砖、花岗岩重新取色。

院外环境（航拍只给出俯视，没有近景照片）：
1. 树种是按航拍里树冠的颜色和形状归类的：
   - 西侧是垂柳为主，与浅绿落叶树、深绿阔叶树混栽；
   - 北、东、南是深绿的樟树类阔叶树；
   - A1 东侧是紫叶李类紫红树林，夹几棵红叶树；
   - 另有浅绿的落叶树。
   每棵树是程序生长的（空间殖民算法），不是某个具体品种的标本。
2. 树的位置按航拍里各片林地的范围随机布置，不是逐棵对位；只有几棵显眼的孤植树按位置放置。
3. 远处一圈树林和林下灌木，是为了把地平线收住，航拍画面外的部分没有依据。
4. 地形起伏、池塘深度和岸坡：航拍看不到，按常见园林做法定为水面 −1.45 m、水深约 0.4–0.9 m、草坡缓起。栏杆一侧水面直接到石砌挡墙，与航拍里荷叶贴着栏杆一致。
5. 铺装规格：红砖平台 0.3×0.6 m、南广场 0.6×0.9 m、西南广场 0.6×0.6 m、冰裂纹石块约 0.3–0.6 m。航拍分辨率看不清砖缝，这些都是常用规格。粉色园路的灰色菱形嵌块、红褐色边条按航拍画出。
6. 石坊的断面（柱 0.32 m 见方、高约 4.3 m、横梁两端出挑）、灯柱灯头样式、雕塑的辐条数、栏杆的柱距和两道横杆、座椅形式、花池高度：按航拍轮廓和常见做法估的。
7. 喷泉：主池是涌泉，做成白色翻滚的水丘加上水面泡沫；西北小池是一圈 12 个小喷头。形态按航拍里的白色水花推断。
8. 石板桥按航拍里两列方石板的样子做成平桥，下面加了石梁和桥墩。

## 仍与资料有差异的地方

1. **B1 院树池位置**：按航拍定位。A2 那张照片在排版时被裁切并纵向拉伸约 1.47 倍，无法唯一反算机位，它暗示的西北角树位与航拍不一致，这一点没有解决；A2 对照图为看清立面隐藏了树木。
2. **楹联文字留空**：照片里只能认出零星几个字，按要求没有补字。B3 北亭匾额同样留空。已做出的匾额：A1“鳴鳳學堂”、A2“芙蓉學堂”、A5“太華春光”、B1 亭“春色滿園”、B3 南亭“步蟾”。
3. **B1 亭碑**：照片上是金色人物浮雕，这里只做了金色浮雕板的位置和形制，没有雕人物。
4. 山面窗带、门窗棂格比实物简化；瓦面没有做局部破损、补瓦和青苔。
5. 除航拍外，其余对照机位是按照片手工对位的，透视接近但不是严格反算；B3 南向照片也有排版拉伸。
6. 院外树木：航拍里的树冠更大、形态更多样，有几处是成片连在一起的。程序树的轮廓更规整，颜色也比照片均匀。航拍上方的道路和车辆按要求没有做，那里是树林。
7. 池水颜色：照片经过调色，水面偏灰蓝；渲染按自然的浑绿池水处理，所以比照片暗一些。
8. A3 檐廊对照图：院外树木会遮挡东面的天光，这张的曝光提高了约 0.6 档，照片本身也是阴影里的均匀光。

- 法线：所有封闭构件按有向体积检查，反向 0 个（共 5175 个封闭壳）；所有屋面望板朝上。
- 共面重叠（会闪烁）：
